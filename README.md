# SIGA-ARMP-SUS-2.0
O SIGA-ARMP SUS é um sistema de apoio à gestão de medicamentos nas UBS do SUS, desenvolvido para prevenir desabastecimentos e reduzir desperdícios por vencimento. Oferece controle de estoques, monitoramento de validades, cálculo do ponto de pedido e sugestões de remanejamento entre unidades de saúde.
